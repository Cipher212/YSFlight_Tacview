The first release of the YSFlight Replay Viewer for scoring RvB events.

**To install:** download `YSFlight-Replay-Viewer-v1.0-win64.zip` below, unzip it anywhere, and double-click `YSFlight Replay Viewer.exe`. Nothing else is needed; Python is included. If Windows says "Windows protected your PC", click **More info** > **Run anyway**. `README.txt` in the zip explains how to use it, on one page.

**What it does**
- Merges the replays that several players recorded of one event into one timeline. Pick them all at once with **Whole event from a folder...**
- Shows the event in 3D on the map, with every aircraft, ground object and weapon drawn with its game model. Weapon trails show the kind of weapon, and aircraft cast YSFlight-style shadows.
- For every kill and death it shows the evidence and how likely each cause is:
  - missiles re-flown with the game's own rules, including as the shooter's game saw the target;
  - a damage log for every aircraft;
  - the nearest aircraft and ground objects at a crash;
  - ground objects counted as destroyed only when the replays agree.
- Tabs for Pilots, Kills, Deaths, Ground targets and Messages. Search, and jumps to the next kill or the next item to review.
- A review queue: confirm or reject each kill and death and add a note. The marks are saved next to the event file.
- A top view of the map (T), SAM and AAA range rings, better lighting, and adjustable sizes.

It gathers the evidence; the scorers make every call.
