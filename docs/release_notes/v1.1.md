Fixes from testing v1.0 on RvB 6.

**To install:** download `YSFlight-Replay-Viewer-v1.1-win64.zip` below, unzip it into a new folder, and double-click `YSFlight Replay Viewer.exe`. The window title shows the version.

- **Black smoke** now only trails an aircraft that really goes down. Before, a replay that showed an aircraft tumbling for a moment because of lag left smoke behind it that never ended, even though it kept flying. The damage log follows the same rule. Rebuild your events to be safe; the smoke fix works on old event files too.
- **Tab** only switches between aircraft. It no longer jumps to buttons or text boxes, so keys like P and Space always reach the viewer. Clicking in the 3D view leaves any text box.
- **Start / Restart** is the new name of the top-bar button that plays the replay from the beginning.
- The **ACES07 font** is used everywhere, and UI words start with a capital ("Throttle", "Health 35/40").
